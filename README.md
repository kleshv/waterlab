# WaterLab · финансы

Кабинет учёта сети WaterLab: выручка и литры по точкам, расходы, коммуналка с тарифами, оплаты аренды и коммуналки, взаиморасчёт и динамика.

## Как устроено
- **Страница** (`index.html`, `shim.js`) лежит здесь и открывается через GitHub Pages. В коде нет ни данных, ни паролей.
- **Данные** хранятся в Supabase (регион Frankfurt). Без входа по email и паролю база ничего не отдаёт.
- **Доступ** есть только у пользователей из таблицы `allowed_users`. Регистрация закрыта, новых пользователей добавляет владелец в панели Supabase.
- Каждое изменение пишется в журнал `docs_history`: кто, когда, что было и что стало.

## Файлы
- `config.js` — адрес проекта Supabase и публичный ключ (anon). Этот ключ публичный по задумке: без входа он ничего не открывает.
- `schema.sql` — таблицы, права доступа, журнал изменений.
- `gen_data.py` — сборка SQL для переноса данных.

## Добавить пользователя
1. Supabase → Authentication → Users → Add user (email, пароль, Auto Confirm).
2. SQL Editor: `insert into allowed_users(email,name) values ('email@example.com','Имя');`

## Убрать доступ
`delete from allowed_users where email='...';` и удалить пользователя в Authentication → Users.
